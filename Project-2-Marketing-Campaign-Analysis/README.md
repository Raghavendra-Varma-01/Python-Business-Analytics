# Project 2 — Marketing Campaign Analysis

## Objective

Analyze customer data to understand purchasing behaviour, spending patterns, and marketing campaign responses using Python.

## Project Scope

The project explores customer demographics, product spending, purchasing channels, and campaign performance to identify patterns in customer behaviour.

## What It Is Used For

- Understand customer purchasing behaviour.
- Analyze spending across different product categories.
- Compare purchases across web, store, and catalog channels.
- Evaluate marketing campaign response rates.
- Identify customer segments and spending patterns.
- Support data-driven marketing and customer engagement decisions.

## Tools and Concepts Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Statistical Analysis
- Data Visualization

## Project Files

- `Marketing_Campaigns.ipynb` — Interactive Python analysis.
- `Marketing_Campaigns.html` — HTML notebook export.
- `Marketing_Campaigns_Report.pdf` — Analysis report.

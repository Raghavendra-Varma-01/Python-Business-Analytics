# Project 1 — AAL Sales Analysis

## Objective

Analyze AAL's US clothing sales data using Python to identify sales trends and generate actionable business insights.

## Project Scope

The project examines sales and unit data across a three-month period, focusing on monthly trends, geographical performance, customer groups, and time-based patterns.

## What It Is Used For

- Monitor daily and monthly sales performance.
- Compare sales revenue and units sold across October, November, and December.
- Identify state-wise sales patterns across the United States.
- Analyze purchasing behaviour across customer groups.
- Examine time-based sales trends.
- Support inventory planning, marketing decisions, and store performance analysis.

## Tools and Concepts Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Data Cleaning and Normalization
- Statistical Analysis
- Data Visualization

## Project Files

- `Sales_Analysis.ipynb` — Interactive Python analysis.
- `Sales_Analysis_Report.pdf` — Completed analysis report.
- `Sales_Analysis.html` — HTML notebook export.
